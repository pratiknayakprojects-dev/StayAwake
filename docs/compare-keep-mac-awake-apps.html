Keep-awake apps for Mac, compared

Four common ways to stop a Mac sleeping, what each is good at, and the one limit that decides the choice: what happens when you close the lid.

Disclosure: I'm Pratik, and I built StayAwake, one of the four. The others are free, good, and I say where they're the better pick. I describe them from their own documentation, so check each before relying on it.

The short version

  • Need to stop sleep while the lid is open? Use caffeinate, KeepingYouAwake or Amphetamine. They're free.
  • Want lots of triggers and automation? Amphetamine.
  • Need it to keep running with the lid closed and no external display? That is what StayAwake is for. It's paid.

caffeinate (built into macOS)

Free and already on your Mac. Run it in Terminal. -i stops idle sleep, -d stops display sleep, -s stops system sleep on AC power, and -t sets a timeout. It has no menu and you manage it yourself. A lid close is a separate trigger, so it still sleeps the Mac. See the lid-close guide.

KeepingYouAwake (free, open source)

A menu bar app that wraps caffeinate, per its own README. It's the easiest free option for stopping sleep with the lid open. Because it uses the same mechanism, its README says it works with the lid open.

Amphetamine (free, Mac App Store)

A feature-rich menu bar app: timed sessions, triggers based on apps or Wi-Fi, and more. It has its own closed-display mode, and the requirements for that mode are in its documentation, so read them for your setup. If you want automation and no price tag, start here.

StayAwake (paid, 7-day free trial, $4.99 once)

A small menu bar app focused on one case: keep the Mac running with the lid closed, no external display. It runs pmset disablesleep through a helper you approve once. An auto-stop timer turns it off, closed-lid mode stops itself if the Mac runs hot or the battery falls below a level you choose, and if the app quits, crashes or is force-quit, the helper restores normal sleep. Universal for Apple silicon and Intel, macOS 13 or later, signed and notarized. It does fewer things than Amphetamine. Source is MIT on GitHub.

How to choose

  • Lid open, want it free: KeepingYouAwake or caffeinate.
  • Want triggers and sessions: Amphetamine.
  • Lid closed, on battery, no display: StayAwake, or sudo pmset -a disablesleep 1 and remember to turn it off.
  • Lid closed with a display and power: clamshell mode is built in, so you may not need any app.

Closed-lid use warms the Mac. Don't run it sealed in a bag; use a timer. StayAwake also stops closed-lid mode on serious heat or low battery.
