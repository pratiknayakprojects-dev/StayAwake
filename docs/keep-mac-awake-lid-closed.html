How to keep a Mac awake with the lid closed (without an external display)

You start a big upload or a long build, close the laptop, and it stops. Here is why that happens, which fixes work, and which don't.

Disclosure: I'm Pratik, and I built StayAwake, the app mentioned near the end. The first sections are useful without it.

Why closing the lid sleeps your Mac

macOS treats a lid close as its own sleep trigger, separate from the idle timer. Most "stay awake" tools work by telling macOS "something is busy, don't sleep because of inactivity". That stops idle sleep, but the lid close is a different event, so on its own it still puts the Mac to sleep.

The one built-in exception is clamshell mode, covered below. Outside it, a closed laptop sleeps, and on battery that is the main thing protecting you from a hot, dead laptop in a bag.

What caffeinate does and doesn't do

caffeinate is a command built into macOS. It holds a power assertion for as long as it runs.

caffeinate -d   # keep the display on
caffeinate -i   # prevent idle sleep
caffeinate -s   # prevent system sleep, only while on AC power
caffeinate -t 3600 -i   # same as -i, for one hour
  • -i and -d stop the Mac sleeping from inactivity while the lid is open.
  • -s goes further, but Apple's man page says it only applies on AC power. On battery it does nothing.
  • None of these override a lid close. They are the right tool for "don't sleep while I'm away from the keyboard", not for "keep running with the lid shut".

KeepingYouAwake is a front end for caffeinate, so it has the same limit and only works with the lid open. Amphetamine is a separate app with its own closed-display mode; check its documentation for the requirements.

Clamshell mode (needs an external display)

Apple supports closing the lid while working, as long as the Mac is plugged into power, an external display is connected, and an external keyboard or mouse is connected (connect these before closing the lid; check Apple's current wording for your macOS version). The Mac then runs on the external display with the lid closed. It's reliable and fully supported. If you have that desk setup, you don't need anything else.

It doesn't help when you're on battery, or have no display, which is exactly when most people hit this problem.

The command-line way: pmset disablesleep

pmset has an undocumented flag, disablesleep (it isn't in the man page, but pmset -g reports it as SleepDisabled), that stops all sleep including lid close:

sudo pmset -a disablesleep 1   # on
sudo pmset -a disablesleep 0   # back to normal

It generally works, though behaviour can vary by Mac and macOS version, and it needs root. The risks are practical: if you forget to switch it back, the Mac stays awake whenever you close it, including in a bag, where it can get hot and drain the battery. If you go this route, set a reminder, or run something that reverts it for you.

Where StayAwake fits

StayAwake is a menu bar app that does the above for you. "Keep Awake" uses a normal power assertion. "Keep Awake When Lid Closed" runs pmset disablesleep through a small helper you approve once. The part I care about is the cleanup: a timer (10 minutes to 3 hours) switches it off for you, and if the app quits, crashes or is force-killed, the helper restores normal sleep. Closed-lid mode also stops itself if macOS reports serious heat or the battery falls below a level you choose (10% by default), and sends a notification saying why. Quick tips for closed-lid use

  • Plug in if you can. A closed, working Mac on battery drains faster than you'd expect.
  • Don't leave it running in a sealed bag. Give it airflow, and use a timer. StayAwake's heat and battery cutoffs are a backstop, not a reason to skip this.
  • Check that your task survives a network change if you're moving around. Closed-lid mode keeps the Mac running; it can't keep a Wi-Fi connection that goes out of range.
